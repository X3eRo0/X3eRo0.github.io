Games

1 min read

Recent backup activity split between currently installed games and the rest of the archive.

Here is a list of games currently installed on my gamestation.

I have a strict policy of mostly playing single-player games to keep my sanity intact. That said, I still enjoy a good LAN party with my IRL friends, so I do make room for LAN multiplayer games. Those are usually older PC games from the era when local area network support was common. These days, a proper LAN option in a multiplayer game feels almost as rare as modern games shipping on physical disks. And yes, I absolutely love both LAN games and physical editions.

I use Ludusavi, an open source tool for backing up save data. I also run a script every 30 minutes that scans all Wine prefixes on my game drive and extracts save files into a backup directory. That backup directory is then pushed to a private Git repository for redundancy. This setup lets me preserve my saves while also using Lutris, the Linux game launcher and manager I rely on to track how many hours I have put into each game.
